# Voci Design

## Direction

Voci uses the `editorial-greeting` app direction: a calm, personal learning workspace that puts the next exam preparation task before app chrome. The visual device is the vocabulary card: a large typographic word surface, supported by quieter task controls.

## Tokens

- Ground: `#f3f5f0`
- Surface: `#ffffff`
- Ink: `#1f2926`
- Accent: `#1b6e66`
- Alert: `#b74c42`
- Radius: 22px for surfaces, fully rounded controls

Instrument Sans handles interface text and Instrument Serif is reserved for the main greeting, word prompts, and result figures.

## Interaction

Buttons use a short transform response on pointer input. Cards give clear selection, correct, and incorrect states through background colour. Motion is reduced for users who request reduced motion.

## Responsive behavior

Desktop uses a two-column workspace. On phones, learning setup, dashboard tiles, and activity controls stack into one reading column while the matching game keeps its two language sides.
